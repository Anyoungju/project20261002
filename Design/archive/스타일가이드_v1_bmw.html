Overview

개요

이 가이드는 npx getdesign@latest add bmw로 설치한 DESIGN.md(BMW corporate 디자인 분석)를 원천으로 Buildcare AI 화면 설계에 맞게 재구성한 것입니다. 모든 값은 토큰으로 참조하며 hex를 직접 쓰지 않습니다. 브랜드 서체 BMW Type Next Latin은 라이선스 서체이므로 Inter 700/300(한글: Noto Sans KR)으로 대체합니다.

Notice Card — 1차 참고용 고지

Buildcare AI의 분석 결과는 이미지 기반 1차 참고용 정보이며, 법적·구조적 안전 판정을 대체하지 않습니다. 위험 가능성이 판정된 경우 반드시 자격 있는 전문가의 점검을 받으세요.

08 · Principles

Do & Don't

Do

  • 모든 페이지는 --canvas(흰색) 위에 두고, --surface-dark는 히어로·CTA 밴드에만
  • 주요 CTA = Primary 블루 + 흰 글자 + 0px 직각 모서리
  • 제목은 700, 본문은 Light 300 — 대비를 유지
  • 인라인 CTA는 UPPERCASE + 1.5px 자간 + › 화살표
  • 카드 사진은 --surface-card 플레이트 위, 제목은 아래에
  • 섹션 리듬은 80px로 일정하게
  • 밝음 → 다크 히어로 → 밝음 → 밝음(soft) → 다크 CTA → 푸터 순으로 표면 교차

Don't

  • 블루 외 다른 브랜드 액션 컬러 추가 금지
  • 둥근 버튼·필 버튼 사용 금지 — 직각이 브랜드 버튼
  • 500 굵기 사용 금지 (700 / 400 / 300만)
  • 본문을 굵게 처리 금지
  • 카드에 드롭 섀도 금지 — 깊이는 색면과 사진으로
  • M 트라이컬러를 CTA 채움색으로 사용 금지
  • 제목 자간을 음수로 좁히지 않기 · hex 값 직접 쓰지 않기
09 · Responsive

반응형

터치 타깃 최소 48×48px(WCAG AAA 44px 상회). 모바일에서 필터 칩은 가로 스크롤, 내비는 햄버거로 전환합니다.
